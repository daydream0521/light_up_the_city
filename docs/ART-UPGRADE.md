# 《点亮夜城》v2 美术升级说明（Phase C / feature/v2-art）

本轮只做城市视觉升级，不改游戏规则、不改关卡配置、不改交互与光路逻辑。
修改集中在 `src/scene/cityGeometry.ts` 与两个新的独立模块 `src/scene/cityBuildings.ts`、`src/scene/cityLife.ts`；
`CityScene.ts` 仅新增 4 行整合钩子（导入、字段、构造、每帧 `cityLife.update(...)`），未触碰镜面、光路、镜头与关卡逻辑。
`src/game/levels.ts`、`src/game/optics.ts`、`src/main.ts`、`src/ui/GameUI.ts` 未修改。

## 1. 新增建筑原型（全部程序化，共享几何与材质）

| 原型 | 特征 | 主要分布 |
| --- | --- | --- |
| 住宅公寓 `buildApartment` | 坡顶/屋顶水箱/空调机位，密集窗格与窗内剪影 | 街区 1 主体、各街区外环住宅塔 |
| 退台商业楼 `buildCommercial` | 2–3 层退台、立面霓虹竖条、高层屋顶广告牌 | 街区 2 主体与外环 |
| 仓库厂房 `buildWarehouse` | 坡顶、卷帘门与门头工作灯带、屋顶通风管/卧罐 | 街区 3 主体 |
| 公共建筑 `buildCivic` | 柱廊、山花、台阶，低层宽体量 | 街区 4 主体与外环 |
| 穹顶堂 `buildDomeHall` | 鼓座+穹顶+环廊柱+发光环带 | 街区 4 地标 |
| 钟楼 `buildClockTower` | 四面发光钟面+指针、锥顶、信标 | 街区 4 外环地标 |
| 退台尖塔 `buildSpireTower` | 三段退台+锥尖+航空信标 | 街区 2 外环地标 |
| 水塔 / 烟囱 `buildWaterTower` / `buildChimney` | 四腿水仓、红环烟囱与信标 | 街区 3 外环天际线 |
| 储罐 / 围栏 / 树 / 喷泉 / 庭院 | 生活化填充物，打破网格重复感 | 各街区按主题权重 |
| 河岸招牌 `buildQuaySign`、木码头 | 面向运河的招牌、码头平台+系船柱+货箱 | 运河两岸 |

差异来自**体量组合与构件**（退台、坡顶、柱廊、穹顶、塔楼轮廓），不是更多随机颜色或随机高度。

## 2. 四街区空间结构与记忆点

- **街区 1 · 旧城住宅**（关卡 1–2）：高密度小体量公寓+坡顶，庭院与行道树，外环中带坡顶的住宅塔与电视天线信标。
- **街区 2 · 商业霓虹**（关卡 3–4）：退台商业楼、立面霓虹竖条、屋顶广告牌，外环最高天际线与退台尖塔地标；沿河一侧为招牌码头岸线。
- **街区 3 · 工业仓储**（关卡 5–6）：低矮厂房与仓库、储罐场、围栏堆场，外环水塔与红环烟囱构成工业天际线；窗少、以门头工作灯带表现复苏。
- **街区 4 · 市政文化**（关卡 7–8）：柱廊公共建筑、穹顶堂、喷泉广场与成排树木，外环钟楼地标；沿河为林荫步道与木码头。
- **运河**：原中央纵向道路改为运河（水面+驳岸+栏杆），保留横向主路与中央桥（新增桥拱与桥灯），桥灯/运河灯随城市复苏点亮；码头伸入街区 4 一侧水面。
- **外缘天际线**：地图四边新增一圈低饱和远景楼群（运河与主路端头留口），增强轮廓层次。

关卡操作格（镜面/分光器/障碍/目标/光源占用格）依旧完全留空；网格内建筑限高约 2.0，低于光束高度 2.25，保证镜面、光束、目标辨识度优先。

## 3. 城市复苏（渐进亮灯）增强

`cityLife.ts` 以每帧 `update(elapsed, delta, levels)` 驱动，输入为既有的四街区进度值：

- **窗灯依次亮起**：每扇窗持有随机阈值，街区进度超过阈值时该窗的暖光覆盖实例才出现（InstancedMesh 矩阵开关，仅变化时写缓冲）。
- **窗内生活剪影**：约 7.5% 的窗附带深色剪影片，随街区进度淡入，只在亮窗前可见。
- **商业/工业照明恢复**：霓虹竖条、广告牌、门头灯带沿用街区招牌材质的既有进度动画。
- **街道生活感**：4 辆汽车灯（前照灯+尾灯精灵）沿横向主路行驶并爬上桥面，按全城平均复苏进度分批出现；路灯池光沿用既有动画。
- **江岸变化**：运河水面新增每街区一条暖色倒影光带（透明度随进度+微 shimmer）与桥下倒影；运河灯/桥灯随平均进度点亮并带轻微闪烁。
- **终局汇聚**：每个街区进度接近满值时升起一道光柱精灵，全城满值时中心出现缓慢呼吸的金色辉光，形成分区→全景的层次汇聚。
- 信标灯（烟囱/塔顶/天线）按相位闪烁。
- `prefers-reduced-motion` 下：车静止、无 shimmer/闪烁/呼吸，仅保留进度驱动的静态结果。

## 4. 性能

- 复用既有 `unitBox`/`windowGeometry` 与共享材质；新增几何均为低段数基础体（圆柱 8–12 段、锥 10 段、球 12×10）。
- **零新增 PointLight**：复苏全部通过 InstancedMesh 实例开关、材质 emissive/opacity 与加法混合精灵实现；灯光数量与 v2 玩法分支一致（4 街区灯 + 关卡器件灯）。
- 栏杆柱、窗、亮窗覆盖层、剪影均使用 InstancedMesh；远景楼群为无阴影简单盒体。
- 亮窗覆盖层仅在阈值跨越时写 instanceMatrix，稳态零写入。
- 构建产物 gzip 约 158 kB（玩法分支为 153 kB），增量约 5 kB gzip。
- SwiftShader 软件渲染下截图脚本测得帧率仅 2–3 FPS（软件光栅化瓶颈，与美术增量无关）；真实 GPU 设备的增量 draw call 主要来自建筑构件与精灵，约 +300 个静态网格，无逐帧分配。

## 5. 截图审查

审查脚本 `tests/e2e/art-review.spec.ts`（固定流程：开场全景两角度 → 四街区关卡视角 → 终局两角度），
截图存于 `test-results/art-0*.png` 并复制到 `docs/screenshots/`。

第一轮发现的问题与修正：
1. 商业楼"冠部光带"从俯视呈现整片青色屋顶 → 删除冠部光带，改为立面霓虹竖条+高层广告牌。
2. 工业/市政区窗密度过稀，终局复苏偏弱 → 仓库改为整排窗+门头灯带，公共建筑恢复常规窗密度。
3. 终局光柱/水面光带过弱不可见 → 提高透明度与光柱尺度。
4. 网格内商业楼广告牌可能接近光束高度 → 广告牌仅限外环高层（高度 > 2.0）。

审查视角覆盖：建筑轮廓与密度（开场全景）、街区差异（四个关卡视角）、灯光层次与过曝（终局）、复苏前后对比（开场暗城 vs 关卡中已复苏街区 vs 终局全城）。

## 6. 美术收尾：终局演出与自由城市观赏

### 解谜机关退场

- `CityScene.showFinale()` 记录 `finaleClearAt = elapsed + 1.0`：终局镜头拉远（3.4s）开始约 1 秒后调用既有 `clearLevel()`（内部含 `clearBeam()`），一次性清除镜面、分光器、光源、目标、障碍、光束、脉冲、终点精灵、悬浮标签与命中检测对象，并释放其几何/材质。
- 成功反馈保留：过关时的粒子庆祝与结算 toast 仍先于终局出现；清场发生在拉远过程中，演出完整。
- 刷新已通关存档 → 进入页「俯瞰夜城」→ `showFinale()` 同样触发清场，不会残留启动时预建的最后一关机关。
- 从观赏返回关卡（进度点选关）或「再玩一次」时，`setLevel()`/`loadLevel()` 重建机关并恢复交互与关卡镜头约束。

### 自由城市观赏

- 终局镜头补间结束后进入自由观赏：复用 OrbitControls，桌面左键旋转、右键平移、滚轮缩放（zoom 0.4–8，全景到建筑特写）；俯仰角放宽至 0.06π–0.47π，支持接近垂直的俯瞰；移动端单指旋转、双指缩放平移（OrbitControls 默认触摸映射）。
- 进入自由观赏即停止自动旋转；工具条提供「自动环视」开关（aria-pressed）。
- 镜头目标每帧钳制在 |x|,|z| ≤ 11.5、y ∈ [0.2, 8]；正交投影缩放不改变相机距离，配合俯仰上限避免穿地/穿楼与无限偏离。
- 终局工具条（右下）：回到全景、自动环视、隐藏界面；隐藏后仅保留一枚「恢复界面」悬浮按钮，并移除终局渐变遮罩与顶栏，避免遮挡城市主体。
- `playwright.config.ts` 支持 `E2E_PORT` 环境变量，便于多工作树并行跑 e2e。
