# v3 主线章节与关卡来源

01–09 沿用雨夜之城已有主线、ID 与存档格式。既有关卡来源及 MIT 声明见 [关卡移植说明](PORTING.md)。

10–25 为使用现有 Reflection 规则的新布局。本轮从可实现的光路出发，筛选分流点、共享折点、固定器件与闸门，再把部分器件拆入库存，留下需要在棋盘上决定的放置点。新增布局与解法独立于上游布局。下表难度是排列目标，根据库存分配、支路依赖和闸门约束排序，最终由盲玩确认。

参考步数来自选定操作序列，可有更短解。测试以现有引擎核对初态、库存、命中、背灯和闸门，并用正式点格规则重放新增关卡。参考操作只放在测试代码中。盲玩时可直接从首页进入城市之旅。

两座新城市的关卡使用同风格局部沙盘，按区推进四组标灯。收藏馆和章节末复用原有完整建筑模型、昼夜与机位控制。上海演出使用既有「点亮两岸」，爱琴演出由黄昏推进至入夜。三张首页卡片使用项目既有实拍图。
