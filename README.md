# 点亮夜城 · Light Up the City

一款纯前端、程序化生成的浏览器 3D 光路解谜游戏。翻转屋顶镜面、安放库存器件、转动光塔，让光束穿过分光镜与闸门，点亮每一盏背灯，依次唤醒四个雨夜街区、九段街角。

## 在线体验

[打开 Qoder Sites 公网版本](https://light-up-the-city-oqwsk12x62f.qoder.zone)，无需登录。**公网当前为六关 Reflection 版本**；`feature/v2-puzzles` 分支已推进到统一规则的九关主线（Task A.2），按开发计划整体验收后再更新公网部署。实际验收记录与关键截图见 [验收记录](docs/ACCEPTANCE.md)。

## 本地运行

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。生产构建：`npm run build`；预览构建：`npm run preview`；逻辑测试：`npm test`。

真实 Chrome 验收：`npm run test:e2e`（自动启动开发服务器，默认使用本机 Chrome，可通过 `CHROME_PATH` 指定浏览器）。测试覆盖直接点击 3D 器件、九关完整流程（五关教学 + Reflection 移植四关，含库存放置/取回、背灯、闸门超额判定、通关条件面板、评分、刷新续玩、终局与重玩）及移动端触摸，截图写入 `test-results/`。移植关卡的来源、许可与规则对比见 [docs/PORTING.md](docs/PORTING.md)。

## 操作与规则

主线九关统一使用 Reflection 规则引擎（`src/game/reflection.ts`），不再有旧版能量限制：

1. 点击「开始点亮」。关卡开始**不强制**阅读规则；右上角「说明」可随时查看本关完整玩法。
2. 点击场景中的器件旋转/翻转：镜面在 `/` 与 `\` 间翻转；背灯镜四向旋转（金色背灯一面被光击中即点亮）；分光镜既反射也让光直行；闸门切换南北/东西轴。带灰色锁环的器件不可调整。
3. 有库存的关卡：底部「库存器件」坞选中器件 → 点击发亮的屋顶放置；每次放置后自动取消选中；「取回」可收回放错的器件。
4. 通关需同时满足：背灯点亮数达标、库存全部放上屋顶、场上器件全部被光照到、闸门被光**恰好**穿过目标次数（超额同样失败）。右上角「通关条件」面板实时显示每项条件的满足状态。
5. 可拖动空白处转动视角、滚轮缩放；「重置」只重置当前关。
6. 过关按操作次数评 1–3 星（不超过标准步数得 3 星）；个人最佳按最少操作次数记录。点击顶部进度点可重玩已解锁关卡。
7. 九关全部点亮后可查看城市全景，并选择「再玩一次」。

声音默认关闭，点击声音按钮开启合成雨声与反馈音。进度与静音偏好仅保存在当前浏览器，无需登录；关卡重排后旧进度自动重置，仅保留静音偏好。

## 技术

- Vite + TypeScript + Three.js，无后端、远程模型或贴图依赖。
- `src/game`：与渲染无关的关卡、Reflection 光路引擎、评分和存档规则。
- `src/scene`：程序化城市、3D 交互、镜头、雨与灯光。
- `src/ui`：语义化界面、通关条件面板与流程状态。
- `tests`：光路规则与九关可解性回归测试、真实浏览器 E2E。
