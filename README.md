# 点亮夜城 · Light Up the City

一款纯前端、程序化生成的浏览器 3D 光路解谜游戏。旋转屋顶镜面、借助分光器分配有限的光塔能量，让光束抵达每一栋目标建筑，依次唤醒四个雨夜街区、八段街角。

## 在线体验

[打开 Qoder Sites 公网版本](https://light-up-the-city-oqwsk12x62f.qoder.zone)，无需登录。**公网当前为 v1.0（四关反射版）**；v2.0 的分光、能量与八关主线在 `feature/v2` 分支开发，按开发计划于 v2 整体验收后再更新公网部署。实际验收记录与关键截图见 [验收记录](docs/ACCEPTANCE.md)。

## 本地运行

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。生产构建：`npm run build`；预览构建：`npm run preview`；逻辑测试：`npm test`。

真实 Chrome 验收：`npm run test:e2e`（自动启动开发服务器，默认使用本机 Chrome，可通过 `CHROME_PATH` 指定浏览器）。测试覆盖直接点击 3D 镜面、六关完整流程（经典教学两关 + Reflection 移植四关，含库存放置、背灯、闸门、评分、刷新续玩、终局与重玩）及移动端触摸，截图写入 `test-results/`。移植关卡的来源、许可与规则对比见 [docs/PORTING.md](docs/PORTING.md)。

## 操作与规则

1. 点击「开始点亮」。
2. 点击场景中的镜面，或下方对应的镜面按钮，在 `/` 与 `\` 之间切换。
3. 光塔能量有限：每次反射消耗 1 点能量；分光器把入射能量平分成两束垂直方向的光（向下取整）；能量耗尽的光束停止。
4. 每栋目标建筑标有所需能量，收到的能量达到需求即点亮；全部目标点亮才过关。
5. 可拖动空白处转动视角、滚轮缩放；「重置」只重置当前关。
6. 过关按操作次数评 1–3 星（不超过标准步数得 3 星），非基础章节另显示能量利用率；个人最佳按最少操作次数记录。点击顶部进度点可重玩已解锁关卡。
7. 四个街区全部点亮后可查看城市全景，并选择「再玩一次」。

声音默认关闭，点击声音按钮开启合成雨声与反馈音。进度与静音偏好仅保存在当前浏览器，无需登录。

## 技术

- Vite + TypeScript + Three.js，无后端、远程模型或贴图依赖。
- `src/game`：与渲染无关的关卡、光路（反射/分光/能量）、评分和存档规则。
- `src/scene`：程序化城市、3D 交互、镜头、雨与灯光。
- `src/ui`：语义化界面与流程状态。
- `tests`：光路及关卡可解性回归测试。

协作与视觉约定见 [公共设计规范](docs/DESIGN.md) 和 [开发指南](docs/CONTRIBUTING.md)；逐关决策、误判与机制限制见 [关卡设计说明](docs/LEVEL-DESIGN.md)。
